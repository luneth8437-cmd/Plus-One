## 费用与配置候选

以下为官方公开标价的估算，不是已购配置；最终以账户结算页为准。

| 项目 | 小规模起步候选 | 公开基础费用 |
| --- | --- | --- |
| 常驻 Web | 0.5c-512mb（旧名 Starter） | 7 美元/月 |
| 持久 PostgreSQL | 0.1c-256mb（旧名 Basic-256mb） | 6 美元/月，另计数据库存储 |
| PostgreSQL 存储 | 按实际分配容量 | 0.30 美元/GB/月 |
| 定时维护 | 单独 Cron Job，仅验收后开启 | 每项至少 1 美元/月，按运行时间计费 |
| 工作区 | Hobby 起步 | 0 美元工作区基础费，计算资源另付 |

不含存储、流量超额、AI、税费等，Web+DB 起步约 13 美元/月；加入一个最低计费维护任务约 14 美元/月起。套餐名称已更新，旧名仍兼容。[官方价格](https://render.com/pricing)、[计算规格](https://render.com/docs/compute-plans)、[定时任务计费](https://render.com/docs/cronjobs)

付费 PostgreSQL 提供时间点恢复；Hobby 工作区当前恢复窗口三天，Pro 或更高为七天。另应导出逻辑备份，在独立库实际恢复并验证。[备份与恢复说明](https://render.com/docs/postgresql-backups)

## 启用前检查

- 登录核实资源 ID、套餐、数据库到期日和区域；记录非敏感信息，不将连接字符串/密钥写入文档。
- 确认预算后再更改套餐，不为绕过到期自动新建/迁移数据库。
- 外部审核密钥有效、DEBUG=False、moderation=external；缺失密钥将暂缓写入，不切成开发规则。
- 迁移前备份；独立恢复后对用户/活动/聊天数量及关键约束做核验，再变更生产连接。
- 先关闭新匹配，发布兼容代码与迁移，验证 readyz、两身份流程后开启。
- 在生产只运行清理 dry-run，复核保护对象/级联规模；获准后才设置每日 `expire_records` + 小批量清理。
- 保活/数据库检查失败必须使监控任务失败，启用平台告警；不添加公网清理接口。

以上操作尚未在生产执行。代码交付与付费部署批准是两个独立阶段。
